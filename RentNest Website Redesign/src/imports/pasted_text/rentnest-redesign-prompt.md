# RENTNEST — Complete Website Redesign Prompt

## Project Vision

Design a premium, modern, highly interactive rental marketplace platform called **RentNest**. The platform helps users browse, rent, list, manage, and communicate about rental properties including apartments, houses, studios, shared spaces, and premium rentals.

The design should feel:

* Modern and trustworthy
* Elegant but approachable
* Minimal but feature-rich
* Smooth and premium like Airbnb + Zillow + Booking.com hybrid
* Optimized for desktop first but fully responsive for tablet and mobile
* Clean spacing, rounded corners, layered cards, glassmorphism accents, subtle gradients, modern typography, soft shadows, smooth animations, and intuitive UX

The current color palette should remain recognizable, but expanded with more refined and modern variations.
